## Things that will bite you

- **`uv sync` may install the project non-editable.** If `import pinnbp` fails after a sync,
  run `uv pip install -e . --no-deps`.
- **Never compare measured tau to R·C absolutely.** It is ~4× low on a band-passed PPG. The
  loss constrains rank within a batch for this reason; see `ARCHITECTURE.md` finding 3.
- **Don't hand-edit `docs/RESULTS.md`.** Rerun `make experiment`.
- **The `quick` config's numbers are meaningless** (8 test subjects). It exists to prove the
  pipeline runs. Its outputs are gitignored so they cannot be mistaken for results.
- **No GPU, ~1 GB free RAM.** Don't run a Gradle build or an emulator alongside a training run.
